# Gene set resources

The teacher pathway branch uses the following GMT files, which are not included in this repository:

- `hallmark.v2026.1.Hs.symbols.gmt`
- `reactome.v2026.1.Hs.symbols.gmt`

Obtain the matching human gene-set collections through their official sources and follow their access and redistribution terms. Place the files in this directory with the exact names above, or edit `pathways.files` in both YAML configurations to point to the files you obtained. Record the collection versions and download date in your analysis notes. Results can change when gene-set versions change.
